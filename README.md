# Звезда твирлинга

Игра про батон-твирлинг и помпоны — подарок на 10-летие. Играть: https://code-by-mazinger.github.io/twirling-star/ (на iPhone — Поделиться → На экран «Домой»).

## Как играть
- Держи палец на экране — набирается сила броска; отпусти — жезл летит и крутится. Сильнее бросок — больше оборотов и очков.
- Нажми, когда жезл падает в светящийся круг у руки: «Идеально» / «Хорошо». Серия ловлей — множитель.
- Три поймки подряд — чир-момент: 4 секунды жми быстро, девочка трясёт помпонами.
- 7 выступлений (от тренировки до чемпионата мира), 3 сердечка, медали: золото — без падений и половина бросков идеально.
- У каждого выступления своя сцена и фишка: спортзал (разминка), школьная сцена (добрось до звезды), стадион (ветер — беги под жезл), дворец спорта (два жезла), Кубок России (пируэт под жезлом, ×2), ледовый дворец (бросок в такт хлопкам, ×1,5), чемпионат мира (каждый бросок — своя фишка). Перед стартом — карточка с объяснением.
- Звёзды за очки — гардероб: костюмы, жезлы, помпоны. Фиолетовый набор (любимый цвет) — в подарок.
- Первый запуск: имя (хранится только на телефоне) и поздравление с днём рождения — корона и золотой жезл в подарок; в этот день каждый год поздравление повторяется.

## Файлы
| Что | Где |

| Сцена (canvas), девочка, касания, звук, окна | `game.js`, `index.html` |
| Офлайн (новая версия — поменять `VER`) | `sw.js` |

Проверка: `node selfcheck.js`. Для проверок в браузере: `?debug` → `window.TT`.
